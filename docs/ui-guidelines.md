# UI Guidelines

## Accessibility

The application must be ADA accessible, conforming to WCAG 2.1 AA standards. This includes:

- All interactive elements must be keyboard navigable
- Images and icons must include descriptive `alt` text
- Color contrast ratios must meet minimum requirements (4.5:1 for normal text, 3:1 for large text)
- Form fields must have associated labels
- ARIA roles and attributes should be used where appropriate

## Color Scheme

The application should use a warm color scheme. This includes:

- Primary palette based on warm tones such as reds, oranges, ambers, and warm browns
- Avoid cool colors (blues, greens, purples) as primary or dominant colors
- Ensure all color combinations meet ADA contrast requirements
- Support a consistent warm-toned dark mode variant if applicable

## Design System

The application should use Material Design as its design foundation. This includes:

- Follow [Material Design 3](https://m3.material.io/) component guidelines
- Use Material Design typography scale and spacing
- Apply Material Design elevation and shadow principles
- Use Material Design motion and transition patterns
- Leverage a Material UI component library (e.g., MUI for React) where possible
